# AI Assistance Disclosure

This project welcomes contributions from AI agents (Claude, Copilot, Codex, and similar tools) when used responsibly.

Commits with substantial AI contributions are marked with `Co-authored-by` tags and not omitted or otherwise hidden.

## Responsible AI Usage

- Oversight: All AI-generated contributions must be reviewed by a human before submission.
- Attribution: All AI-generated code should be transparently acknowledged.
- Security: AI agents must not introduce intentional security vulnerabilities.
- Quality: AI contributions are held to the same quality standards as human contributions.

## Security Disclosure for AI-Related Issues

If you discover a vulnerability that may have been introduced by AI tooling or generated code that poses security risks:

1. **Do not** open a public issue!!
2. Report privately via email or GitHub Security Advisories
3. Include details about the potential AI involvement
4. Allow reasonable time for investigation and remediation

## AI-Assited, Not AI-Authored

AI-generated output is not accepted blindly and is reviewed before it becomes part of the project.

Architecture decisions, debugging, live testing, and final code review are to always be handled by human developers.

This project should not be considered a fully AI-generated or "vibe-coded" codebase. AI is used as a development aid
and does not act as an autonomous maintainer of this project.
